# 시각 검증 체크리스트 (사용자용)

이 세션에는 브라우저 자동화가 붙어 있지 않고, 홈과 글 상세가 `'use client'`라 서버 HTML에는 본문이 없다. 아래 항목은 사람이 직접 봐야 한다.

실행: `npm run dev` → `http://localhost:3000`

각 페이지를 **라이트/다크 각각** 확인한다. 테마는 헤더의 `[테마: ...]`를 눌러 순환시킨다.

## 페이지별

### `/` (홈)
- [ ] 최상단에 `다미파파의 블로그` 제목이 보인다 (헤더와 별개로 본문에 한 번 더)
- [ ] 그 아래 한 줄 통계 (`글 N편 · 조회 N · 오늘 N명 · 누적 N명`)
- [ ] 연도 제목(`2026`) 아래 `MM.DD 제목` 목록이 쌓인다
- [ ] **`더보기 »`를 눌렀을 때 초기 목록 다음 글이 이어진다** — 건너뛴 글이 없는지 확인. 이번 작업에서 가장 틀리기 쉬웠던 지점
- [ ] 그 아래 `인기 글` 5개, 카테고리 트리, 포스팅 잔디 순서
- [ ] 카드·그림자·둥근 모서리·진입 애니메이션이 하나도 없다

### `/posts/<아무 글>`
- [ ] 제목 → 메타 한 줄 → 가로선 → 본문 순서
- [ ] 본문이 명조체이고 코드블록이 각진 회색 박스
- [ ] 인용문에 좌측 회색 바, 본문 링크에 밑줄
- [ ] 하단 공유 버튼이 `페이스북 / 링크드인 / 링크 복사` 텍스트로 보인다 — **모바일 폭에서도 글자가 보이는지** (아이콘만 남아 빈 버튼이 되지 않았는지)
- [ ] 좋아요/싫어요를 눌렀을 때 `☆` → `★`로 바뀌고 굵어진다 (내가 누른 상태를 알 수 있는지)
- [ ] 이미지가 있는 글에서 로딩 중 회색 사각형이 **다크모드에서 흰색으로 튀지 않는다**
- [ ] **이미지에 마우스를 올려도 확대되거나 흐려지지 않는다** — 최종 리뷰가 잡은 가장 큰 누락. 모든 글의 모든 이미지에 해당
- [ ] 이미지 클릭 시 확대 보기는 여전히 동작한다 (`cursor-zoom-in`은 남겼다)
- [ ] 태그(`#태그`)에 밑줄이 있어 옆의 평문과 구별된다

### `/tags`
- [ ] 떠다니던 태그 클라우드가 사라지고 `#태그 12편 · 3.4%` **단일 컬럼** 목록이 된다 (3열 그리드였던 것을 최종 리뷰 후 폈다)
- [ ] 안내문이 "많이 쓴 태그부터 정렬했어요..."로 바뀌었다 (예전 문구는 사라진 동작을 설명했다)

### `/categories`, `/categories/<slug>`
- [ ] 카드가 사라지고 목록이 된다
- [ ] 카테고리 트리의 `+`/`−`를 눌러 펼치고 접을 수 있다
- [ ] 선택된 카테고리가 배경색이 아니라 **굵기**로 표시된다

### `/search`
- [ ] 검색창이 각진 테두리
- [ ] 결과가 3열 그리드가 아니라 목록

### `/career`
- [ ] 페이지 최상단에 `프로필` 제목이 있다 (최종 리뷰에서 `<h1>` 부재가 발견돼 추가)
- [ ] 타임라인 장식(세로선·점·그라디언트)이 사라지고 텍스트 목록
- [ ] `이력서 | 스토리` 전환이 텍스트 버튼으로 동작한다
- [ ] 각 경력의 펼치기(`+`/`−`)가 동작한다

### `/projects`, `/projects/<slug>`
- [ ] 페이지 최상단에 `놀이터` 제목이 있다 (최종 리뷰에서 `<h1>` 부재가 발견돼 추가)
- [ ] 글 상세가 좌우 2단이 아니라 **단일 컬럼**이다 (720px 안에서 2단이라 본문이 45% 눌려 있었다)
- [ ] 뱃지가 알약 모양이 아니라 각지다
- [ ] **아이콘 격자는 유지되고**(놀이터는 런처라 목록으로 바꾸지 않기로 결정) 아이콘이 각지고 그림자·확대가 없다
- [ ] 호버해야만 보이던 정보가 항상 보인다

### `/game/tetris`
- [ ] 게임 화면은 그대로 (의도적으로 범위 밖)

## 전체 공통

- [ ] **모바일 폭 375px에서 가로 스크롤이 생기는 페이지가 없다** — 커밋 `8c1d8ba`에서 고쳤던 문제라 회귀 확인 필수
- [ ] 헤더 내비가 375px에서 두 줄로 자연스럽게 접힌다 (햄버거 메뉴는 의도적으로 삭제)
- [ ] 다크모드에서 흰 배경이 남아 있는 요소가 없다
- [ ] **페이지를 옮겨다닐 때 제목 크기가 튀지 않는다** — 전부 `text-2xl`로 통일했다 (이전에는 홈 1.125rem ↔ 검색 2.25rem)
- [ ] 방문한 글 링크가 보라색(다크모드에서는 연보라)으로 바뀐다
- [ ] **로고를 1초 안에 5번 클릭하면 로그인 페이지로 간다** (숨겨진 로그인 경로, 반드시 확인)

## 어드민 (디자인은 안 바꿨지만 부수 영향 확인)

- [ ] `/admin`에서 글 작성 에디터(TipTap)가 정상 동작한다 — 툴바, 코드블록, 이미지 삽입
- [ ] 어드민 UI의 모서리가 각져졌다 (토큰 공유로 인한 의도된 부수 효과)

## 알려진 잔여 항목

- `components/common/ImageViewerModal.tsx`의 로딩 스피너는 의도적으로 유지 (검은 오버레이 위 모달, 어드민 공유)
- `<Link><Button>` 중첩 마크업은 이번 작업 이전부터 있던 문제 — 범위 밖
- `framer-motion`을 코드에서는 걷어냈지만 `package.json`에는 남아 있음 — 별도 정리 대상
- 사용처가 0개인 파일 3개: `components/common/Modal.tsx`, `components/ui/segmented-control.tsx`, `components/common/Pagination.tsx` — 삭제는 리디자인 범위 밖이라 남겨둠
- `npm run build`는 `OPENAI_API_KEY`가 있어야 완주한다 (어드민 API 라우트가 모듈 스코프에서 클라이언트를 만든다). 이 브랜치와 무관한 기존 조건
